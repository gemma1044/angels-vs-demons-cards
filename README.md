# 翼烬战线 · 天使 vs 恶魔

原创卡牌对战游戏：卡牌是 2D 的，战斗在 3D 战场里进行。打出的角色卡会变成 3D 角色上场，自动与正对面的敌人交战。

```bash
npm install
npm run dev      # http://localhost:5183 （launch.json 里固定了端口）
npm test         # 规则引擎单元测试
npm run sim      # 电脑自对弈，看各卡组胜率（调数值用）
```

## 规则

- 双方各有一座 30 生命的圣所，4 条战线，每条战线每方最多 1 个单位。
- 每回合灵息上限 +1（最多 8）并回满，抽 1 张牌；花灵息把手牌部署到己方空战线。先手首回合不抽牌，后手首回合多 1 点临时灵息。
- 点「开战」结束回合：己方单位从左到右依次攻击正对面的敌人，对方同时反击；对面没人就直接打圣所。刚部署的单位本回合不主动进攻（「突袭」除外）。
- 护甲：每次受伤 −护甲值（最少 1）。贯穿：击杀后溢出伤害打圣所。吸取：进攻造成伤害时己方圣所恢复等量生命。
- 第 20 轮仍未分胜负，圣所生命高者胜。

| 阵营 | 主题 | 风格 | 特点 |

| 恶魔 | 熔渊 | 熔岩深渊 | 直伤、灼烧 |

## 羁绊（12 种，只看自己场上的单位，实时重算）

- 同主题（2 个一档 / 3 个二档）：颂歌、协议、流云、沸腾、血宴、过载。
- 天使 + 恶魔混编（两个主题合计 3 个且各至少 1 个）：同炉（机枢+蚀械）、圣火（圣像+熔渊）、墨夜（云篆+夜棘）；黄昏契约（2 天使 + 2 恶魔）。
- 纯阵营（3 个同阵营且没有另一阵营）：天穹、万魔殿。

具体数值见 `src/game/bonds.ts`，游戏内「全部规则」可查。

## 画面

- 渲染：Three.js（WebGL），HDR + 辉光后处理 + 暗角/色差调色。
- 场景：浮空竞技场，脚下的海随双方卡组变化（天使云海 / 恶魔熔岩 / 黄昏星云），半场后方有对应布景和环境光尘。
- 出牌：卡牌以 3D 形态飞入战场，拍在战线上成为召唤阵，角色从卡面里升起；阵亡时脚下的卡牌一同熄灭。
- 战斗：斩击光弧、命中闪光、打圣所的光束、镜头冲击与抖动、角色主题色轮廓光。
- 手牌：悬停时随指针 3D 倾斜，带全息反光。

## 代码结构

- `src/game/`：纯规则，不依赖浏览器。`cards.ts` 卡牌数据、`bonds.ts` 羁绊、`engine.ts` 回合与战斗（输出事件列表）、`ai.ts` 电脑对手、`decks.ts` 预设卡组。
- `src/scene/`：Three.js。`characters.ts` 用基础几何体拼出六个主题的角色；`battlefield.ts` 战场、后处理、动作与特效；`shaders.ts` 海面、符文、光尘、调色等自定义着色器。
- `src/main.ts` + `src/style.css`：DOM 界面，按引擎事件顺序播放。
- `public/cards/`：卡面插画（600×800 JPEG）。缺图时自动退回代码生成的 SVG 卡面。
- `tests/engine.test.ts`：费用、伤害、羁绊、电脑对手的单元测试。

## 卡面来源

24 张卡面由 Codex 内置出图工具按统一画风规格生成（原创形象，不含文字和边框），原始 PNG（1086×1448）放在 `art/originals/`，未纳入版本库。

## 角色模型（Blender 脚本生成）

24 个角色的 3D 模型都由 Blender 的 Python 脚本生成，导出为 `public/models/<卡牌 id>.glb`，游戏启动时预加载；某个模型缺失时会退回 `src/scene/characters.ts` 里的几何体角色。

- `tools/blender/avd_lib.py`：公共积木（蒙皮躯干、长袍、羽翼、蝠翼、机械翼、废铁翼、披风、荆棘、顶点色 AO 烘焙、导出、预览渲染）
- `tools/blender/build.py`：入口，另含六翼炽辉、火口暴君
- `tools/blender/chars_angel.py` / `chars_demon.py`：其余 22 个角色
- 重新生成全部：`blender -b --python tools/blender/build.py`；只生成某几个：在后面加 `-- icon_seraph lava_tyrant`
- 预览图输出到 `art/model-previews/`（正面和背面各一张）

物体命名约定：`body` 静止主体；`wing_R_*` / `wing_L_*` 翅膀（游戏里扇动）；`spin_x|y|z_*` 自转部件（光环、王冠、圆锯）。材质名带 `veins` 的会在游戏里叠一层流动的熔岩裂纹着色器。

单位脚下是一圈召唤阵（天使六芒、恶魔五角）：卡牌飞入拍到战线上后化成光散开，角色从阵中升起。

## 界面素材

界面是「黑曜石底板 + 鎏金花饰」的方向：卡框、数值徽章（费用/攻击/生命/护甲）、关键词图标、六个主题纹章、阵营徽记、按钮、角花、分隔线、开局主视觉、结算徽记都是图片素材，放在 `public/ui/`，原始生成图在 `art/ui-originals/`。

- 素材由 Codex 用内置出图工具生成，后处理脚本是 `scripts/ui-asset.mjs`（抠纯色底、裁透明边、缩放）。
- 卡牌用容器宽度单位排版，卡框里插画窗口和三个凹槽的位置在 `src/style.css` 的 `.card.faction-angel` / `.card.faction-demon` 两组变量里对齐；换卡框图时改这两行。
- `art/ui-sheet.html` 是全部素材的总览页（开发服务运行时访问 `/art/ui-sheet.html`）。
- `public/ui/panel_frame.png` 目前没有用到（面板用的是 CSS 细金边加角花）。
